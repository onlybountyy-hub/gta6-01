**Solano Heat** — an original open-world crime game set in the sun-soaked coastal city of Port Solano, built with Three.js and plain JavaScript modules. Explore the city on foot or by car: steal and drive vehicles, dodge or fight the PSPD across a 0–5 star wanted system, run with live traffic and pedestrians, and work a five-mission story chain for fixer Lola Marchetti — package runs, a stolen sedan to cool down, a checkpoint race, a three-star cargo run, and a final escape to her boat at the harbor. Full HUD with a live minimap, synthesized engine/siren/weapon audio, and localStorage saves. No build step and no network: every asset is a file in `game/` or generated at runtime.

## Run it

```sh
python3 -m http.server 8000 --directory game
# then open http://localhost:8000 in desktop Chrome
```
